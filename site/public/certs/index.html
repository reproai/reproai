Reproducibility certificates

What this registry shows

A certificate checks that a study's listed output files can be regenerated from its exact code, data, and computing environment. Each entry below is a study whose outputs reproduced exactly.

It does not judge whether the paper's conclusions are correct — reproducible is not the same as correct.

How we make it tamper-evident

Each run is bound to a public timestamp issued after the code and data were locked, so the result could not have been prepared in advance, and is digitally signed by the author and recorded in a public tamper-evident log. The full technical evidence lives on each certificate page and in the raw JSON files it links to.

Prototype registry. Platform adapters (Dataverse and other archives) implement the same standard deposit interface — swapping the archive never touches certificate semantics.
